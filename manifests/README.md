Versioned metadata manifests are the single source of truth for splits — see `docs/PROJECT_BRIEF.md` Section 5.3. The in-domain manifests are in `splits/`; pre-training cross-manipulation manifests are generated into `splits/cross_manipulation_<family>/` by `scripts/build_cross_manip_split.py`. That test split contains real controls plus only the selected held-out family for identities excluded from train/validation. Degradation manifests contain recipes and parent IDs only, never generated media.
